\section{Arquitectura}

El paquete vive en \texttt{src/fibonacci\_photonics/}.

\begin{center}

Los parámetros científicos no están en los scripts: están en
\texttt{configs/figure\_0N.yaml} y se validan al cargarlos. El diseño completo
está en \textit{Arquitectura, flujo y ejecución del proyecto}.

\section{Instalación}

\begin{lstlisting}
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt      # = pip install -e ".[dev]"
\end{lstlisting}

Python $\ge$ 3.10. Dependencias: NumPy, SciPy, Matplotlib, PyYAML y Pydantic~2;
el extra \texttt{dev} añade pytest, Ruff, mypy y \texttt{types-PyYAML}.

\section{Uso}

\begin{lstlisting}
make tests lint
python scripts/run_figure.py figure_01 --method tmm   # una figura
python scripts/run_figure.py all --method both        # todas, ambos metodos
fibonacci-figure 5 --method pwe --workers 8           # comando instalado
python scripts/comparison/run_all.py                  # TMM vs PWE
make documents verify
\end{lstlisting}

Para un orden nuevo de Fibonacci, cambie \texttt{fibonacci\_orders} en el YAML.
Para TM, ponga \texttt{polarization: TM}.
Para otro Drude, edite \texttt{omega\_e\_over\_2pi\_ghz} y \texttt{omega\_m\_over\_2pi\_ghz}.

\section{API principal}

\begin{lstlisting}[language=Python]
import numpy as np
from fibonacci_photonics import PWESolver, TMMSolver, get_solver, load_spec

spec = load_spec()                       # superred del articulo
nu = np.linspace(0.5, 5.0, 2001)         # GHz, > 0 y creciente
scan = TMMSolver(spec).scan(4, np.pi / 6, nu, "TE")
pwe = get_solver("pwe", spec, harmonics_per_layer=16)
r = pwe.semitrace(4, np.pi / 6, nu, "TE")
report = pwe.convergence_report(4, np.pi / 6, nu[::200])
\end{lstlisting}

\begin{itemize}
\item \texttt{solver.semitrace}, \texttt{solver.scan} y \texttt{solver.evaluator}
tienen la misma firma en los dos métodos y devuelven los mismos objetos.
\item \texttt{TMMSolver(spec, algorithm="recurrence"|"product")}: las dos vías de
$R_m$ deben coincidir.
\item \texttt{PWESolver(spec, harmonics\_per\_layer, rule="inverse"|"laurent", workers)}:
$n_{\max}=hF_m$; \texttt{convergence\_report} compara con 1.5 veces más ondas
planas y emite \texttt{ConvergenceWarning} si no converge.
\item \texttt{close\_band\_edges(solver, scan)}: bordes $|R|=1$ y puntas refinados.
\item \texttt{detect\_plasmon\_modes(scan, nu\_min\_ghz, nu\_max\_ghz)},
\texttt{bandwidth\_versus\_angle}, \texttt{compare\_scans}.
\item \texttt{sequence(m)}, \texttt{paper\_fibonacci(m)}, \texttt{build\_cell(m, a, b)}.
\item \texttt{load\_spec(path)}, \texttt{load\_figure(figure\_id)}: YAML validados.
\end{itemize}

Las entradas inválidas (frecuencias $\le 0$ o no finitas, mallas no crecientes,
$\theta\notin[0,\pi/2]$, órdenes negativos, armónicos $<1$) lanzan
\texttt{InvalidParameterError}; los YAML inválidos, \texttt{ConfigError}.

\section{Modelo físico}

Aire $\varepsilon=\mu=1$. Drude $\varepsilon=1-\omega_e^2/\omega^2$,
$\mu=1-\omega_m^2/\omega^2$. Frecuencia graficada: $\nu=\omega/2\pi$ en GHz.

\section{TMM}

Matriz de capa unimodular con $\chi=\mu$ (TE) o $\varepsilon$ (TM).
Producto $T=M_N\cdots M_1$. Recurrencia $R_m=2R_{m-1}R_{m-2}-R_{m-3}$.
$q=(\omega/c)n_A\sin\theta$ (el paper omite $\omega/c$).

\section{Fibonacci}

$S_0=B$, $S_1=A$, $S_m=S_{m-1}S_{m-2}$, $F_0=F_1=1$,
$N_B=F_{m-2}$, $L_m=F_{m-1}a+F_{m-2}b$.

\section{Dispersión}

Banda si $\lvert R\rvert\le 1+10^{-12}$. $kL_m/\pi=\arccos(R)/\pi$.
Los puntos con $\lvert R\rvert>1$ se dejan como NaN, no se recortan en silencio.

\section{Pruebas}

\begin{itemize}
\item \texttt{tests/unit/}: contrato común, validaciones, esquemas Pydantic,
Fourier, matrices de transferencia, PWE frente a TMM, bordes y análisis de bandas.
\item \texttt{tests/analytic/}: límite homogéneo, bicapa de cuarto de onda
($R=-5/3$), $\det T=1$, invariante de Kohmoto, TE$=$TM a $\theta=0$,
dualidad $\varepsilon\leftrightarrow\mu$, Parseval, razón áurea.
\item \texttt{tests/regression/}: valores de referencia previos a la
refactorización y $N_{\mathrm{modos}}=F_{m-2}$.
\end{itemize}

\section{Reproducción de figuras}

Cada \texttt{results/tmm/figure\_0N/} contiene \texttt{data/}, \texttt{output/} y
\texttt{README.md}. Las versiones PWE están en \texttt{results/pwe/figure\_0N/} y
la comparación en \texttt{results/comparison/}. Las imágenes finales son PDF,
PNG (300 dpi) y, para la TMM, SVG.

\section{Solución de problemas}

\begin{itemize}
\item \texttt{InvalidParameterError} con $\nu=0$: el Drude diverge; no incluya el origen en el barrido.
\item $\mu_B=0$ o $\varepsilon_B=0$: polo; el escáner enmascara una vecindad relativa $10^{-6}$.
\item $\lvert R\rvert$ siempre $\le 1$ a $\theta=0$ si $\omega_e=\omega_m$: no es un bug, es adaptación de impedancia.
\item \texttt{ConvergenceWarning}: aumente \texttt{harmonics\_per\_layer} o use la TMM cerca de $\nu_m$.
\item Fig.~6: el original grafica $\nu(\theta)$ relleno, no $\Delta\nu$;
el caption del PRB está incompleto (parámetros inferidos de las Figs.~3--5).
\item \texttt{ImportError}: instale el paquete (\texttt{pip install -e .}) o use \texttt{PYTHONPATH=src}.
\end{itemize}

\section{Extensiones}

Nuevo orden: YAML. Nueva polarización: \texttt{Polarization.TM}. Nuevo material:
implemente \texttt{epsilon\_mu(omega)} con la misma interfaz que
\texttt{DrudeMetamaterial}. Nuevo método numérico: implemente
\texttt{semitrace}, \texttt{scan} y \texttt{evaluator} (protocolo
\texttt{DispersionSolver}) y todo el post-proceso funciona sin cambios.
