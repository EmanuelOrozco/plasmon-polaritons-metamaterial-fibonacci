Regenerar PDF con `make paper`, `make docs` o `make guides`:

- `scientific_paper/` — paper de reimplementación
- `software_documentation/` — API / software
- `guia_conceptual/` — física desde cero
- `solucion_numerica/` — de las ecuaciones al código
- `arquitectura/` — estructura y ejecución
